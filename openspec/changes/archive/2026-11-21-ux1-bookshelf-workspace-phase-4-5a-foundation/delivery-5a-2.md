# 5A.2 草稿视觉差异分类与纠偏批次

- 日期：2026-11-20
- 基线：`redesign-2026` / `d25642aff96ecd866df6f9ee67f938e7f6b52104`
- 输入：`delivery-5a-1.md`、ego lite 草稿 DOM/截图、生产 expanded/medium/compact/详情/阅读器截图。
- 边界：本文件只提出分类、批次和验收场景；owner 确认前不实施纠偏、不继续 6.x。

## 分类原则

### 保留

- A 书架型方向：左侧可收起导航 + 右侧工作区、多标签、不分屏。
- 收藏默认舒适密度、作者 shelf 三态、封面网格、作者栏独立排序与平台名称树。
- 搜索默认封面平铺、单源/聚合来源分组、复选框/主体/Space/Enter/Cmd+Enter 的独立命中语义。
- 详情的信息优先/阅读优先双模式及完整业务字段；预览不是标签、关闭回原焦点、后台打开不抢当前页。
- 动态强调色、语义色、Material Icons、1px 分隔线、浅深主题跟随应用、已有断点入口和 AppSizes/AppSpacing token。
- 已验收的 F1/F2、F5/F8/F10/F11/B4 交互与持久化契约；纠偏不得改写为新的业务语义。

### 调整

- **收藏/作者 shelf**：保留书架导航，但收敛生产中的“书架 + 收藏文件夹”双层信息层级；明确文件夹栏在 expanded/medium/compact 的显隐、折叠和摘要位置，避免同一层级重复表达收藏导航。
- **搜索**：保留搜索配置、来源分组和交互契约；将首屏结果 pane 的信息层级向 A 草稿靠拢，默认先看到封面、标题、来源/作者和状态，搜索配置移入可发现的次级区域。
- **详情**：保留 `ComicPage` 长滚动和全部功能；调整首屏 hero 的封面、标题、作者/来源和主动作关系，使信息优先首屏更接近草稿，不重建详情数据栈。
- **临时预览**：保留 Dialog 和键盘语义；核对三档下 640px 最大宽度、封面槽位、遮罩、左右切换、关闭入口与焦点环，必要时只调整 token 化尺寸和布局。
- **阅读器主题/材质**：保留普通/沉浸模式和单进度契约；将 `BlurEffect`、灰色边界和任何非语义颜色收敛到 `ColorScheme`/token，禁止恢复阅读器深色例外。

### 重构

- **工作区顶栏**：当前 `WindowFrame` 36px + `BookshelfWorkspace` 48px toolbar + `WorkspaceTabStrip` 44px 形成多层 chrome；按 D3/D8 重组为单一合并工作区行。窗口控制、菜单/交通灯、侧栏开关、历史和标签必须在同一行；不得再叠加独立标题栏。
- **阅读器 chrome 行数**：普通阅读工具隐藏时只保留一行工作区行；工具显示时仅追加一行 reader tools；沉浸阅读隐藏工作区行，只保留 reader tools。单击漫画只切换第二行，不重建标签现场。
- **紧凑窗口壳层**：将 compact 覆盖侧栏、遮罩/Escape 和 medium/expanded 偏好恢复统一到合并顶栏状态机，避免窗口缩放时重新创建当前内容。

## 纠偏批次

### Batch A — 合并工作区顶栏与断点壳层

范围：`WindowFrame`、工作区 toolbar、tab strip、书架开关和 compact overlay 的结构重组；不改变标签身份、历史、搜索或收藏数据。

验收场景：

1. expanded：窗口控制/侧栏开关/历史/标签同一行，命令中心在该行，正文从下一行开始。
2. medium：同一行但隐藏命令中心，侧栏可收起且不重建当前标签。
3. compact：侧栏覆盖内容，遮罩/Escape 关闭，恢复宽度还原原偏好、滚动、多选和焦点。
4. 三档切换均无第三条独立标题行；截图逐项记录顶栏物理行数和内容起始坐标。

### Batch B — 收藏、作者 shelf、搜索与详情层级

范围：收藏文件夹层级、作者 shelf 首屏、搜索结果 pane、详情 hero；复用现有卡片、状态和持久化，不改主体/复选框/拖放语义。

验收场景：

1. 收藏 expanded/medium/compact：页面标题、筛选摘要、作者 shelf 和封面网格顺序与 A 草稿一致；文件夹栏只有一个主导航表达。
2. 作者 shelf 折叠/正常/展开：手柄、平台名称、栏内排序和不发起额外请求保持；三态无溢出。
3. 搜索单源/聚合：默认封面平铺；来源分组仍清晰；加载、空态、失败、刷新和复选框不改变首屏层级。
4. 详情信息优先/阅读优先：hero、简介、元数据、继续阅读和最近章节顺序分别符合 D7；返回保持标签现场。

### Batch C — 临时预览与浮层焦点

范围：预览 Dialog 的尺寸、遮罩、切换控件、焦点环和 compact 可用性；不改变预览/标签/请求契约。

验收场景：

1. expanded/medium/compact 打开 Space 预览，封面与概览/目录/详情均可滚动，关闭入口始终可见。
2. 左右切换只更换预览目标；Enter 当前标签打开；Cmd/Ctrl+Enter 后台标签打开。
3. Escape 关闭预览并归还原卡片焦点；底层卡片不误触，选择/滚动/搜索请求保持。
4. 150% 大文字、浅深主题、减少动画下无裁切、无位移动画阻塞和无第二套浮层样式。

### Batch D — 阅读器 chrome 与全局收尾

范围：普通/沉浸阅读顶栏、漫画单击、章节浮层、单进度、主题与减少动画；与 6.1/6.2/6.3/6.7 合并执行，避免重复改壳层。

验收场景：

1. 普通阅读工具隐藏：唯一工作区行 + 内容 + 一条精简进度。
2. 普通阅读工具显示：工作区行下只增加一行 reader tools，共两行；无独立标题栏。
3. 单击漫画只切换 reader tools；标签、章节、页码、阅读方案和后台现场不变；独立按钮/章节/文本不冒泡。
4. 沉浸阅读工具显示：只保留 reader tools；Escape 先关章节浮层，再退出沉浸；第二次恢复工作区行。
5. expanded/medium/compact、浅深主题、150% 和减少动画截图逐项通过；ReaderTopBar 不使用非 token 的模糊/灰色边界。
