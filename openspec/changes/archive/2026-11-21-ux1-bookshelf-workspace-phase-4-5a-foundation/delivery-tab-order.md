# 工作区标签栏布局与拖动排序

- 日期：2026-11-20
- 状态：实现完成，待 owner GUI 复核。

## 实现

- 保持 Notion 式单行顶栏结构：左侧窗口/导航控制，中间标签区，右侧全部标签与新建入口。
- 标签之间增加 1px 分隔线，当前标签继续使用强调容器区分。
- 删除独立拖动手柄，改为长按标签本体拖动排序，避免与窗口拖动冲突；拖动后的顺序写入既有工作区快照，重启后保持。
- 标签栏右侧保留窗口拖动空白区；漫画卡片拖入标签栏时，插入位置显示高亮竖线，释放后在该位置创建后台标签。
- 标签栏绑定工作区 chrome 的即时刷新通知，新增、关闭、排序后立即更新标题和数量。
- 标签拖动期间临时禁用右侧窗口拖动手势，拖动结束后恢复；插入槽扩大为可命中的间隔区域并保持中心高亮线，避免依赖 1px 精确命中。
